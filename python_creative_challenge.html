Day 1: Mad Libs Generator
Strings & Input
Build a fun Mad Libs game that takes user inputs and creates silly stories. You'll learn about string formatting and user interaction beyond simple calculations.
Your Mission:
Create a program that asks for different types of words (noun, verb, adjective, etc.) and inserts them into a pre-written story template. Print out the hilarious result!
💡 New Concepts:
  • f-strings: f"Hello {name}!"
  • Multiple input() calls
  • String concatenation
🌟 Bonus Challenge:
Add multiple story templates and let the user choose which one they want!
Day 2: Number Guessing Game
Loops & Logic
Create an interactive game where the computer picks a random number and you have to guess it. This introduces loops and conditional logic in a fun way!
Your Mission:
Use import random to generate a number between 1-100. Give the user hints ("too high" or "too low") and count how many guesses they take.
💡 New Concepts:
  • import random and random.randint()
  • while loops
  • if/elif/else statements
  • Comparison operators
🌟 Bonus Challenge:
Add difficulty levels (Easy: 1-50, Hard: 1-200) and limit the number of guesses!
Day 3: Password Generator
Lists & Functions
Build a tool that creates secure random passwords. This is your first step into using lists and writing reusable functions!
Your Mission:
Create a function that generates a random password with letters, numbers, and symbols. Let users specify how long they want it to be.
💡 New Concepts:
  • Defining functions: def function_name():
  • Lists: characters = ['a', 'b', 'c']
  • random.choice() to pick random items
  • String method: .join()
🌟 Bonus Challenge:
Add options to exclude certain characters or ensure at least one number and one symbol!
Day 4: Rock Paper Scissors
Game Logic
Create the classic game where you play against the computer. This teaches you about game logic and handling multiple conditions.
Your Mission:
Build a game where the user picks rock, paper, or scissors, the computer picks randomly, and the program determines the winner. Keep score!
💡 New Concepts:
  • Combining everything from previous days
  • Complex conditional logic
  • Score tracking with variables
  • Input validation (handling bad input)
🌟 Bonus Challenge:
Add a "best of 5" mode and show game statistics at the end!
Day 5: To-Do List Manager
Data Management
Create a simple app that lets you add, view, and remove tasks. This introduces working with persistent data structures.
Your Mission:
Build a menu-driven program where users can: 1) Add tasks, 2) View all tasks, 3) Mark tasks as complete, 4) Delete tasks, 5) Exit.
💡 New Concepts:
  • Lists as data storage
  • .append(), .remove() methods
  • Menu-driven programs with while loops
  • List indexing and iteration
🌟 Bonus Challenge:
Add task priorities or due dates, and sort tasks by priority!
Day 6: ASCII Art Generator
Creative Output
Generate patterns, shapes, or text art using code. This pushes your creativity and teaches nested loops!
Your Mission:
Create a program that generates ASCII art patterns like pyramids, diamonds, or creates large text from small characters. Let users customize the size and character used.
💡 New Concepts:
  • Nested for loops
  • String multiplication: "*" * 5
  • Pattern recognition and math in code
  • Formatting output with spaces
🌟 Bonus Challenge:
Create multiple pattern options (triangle, diamond, square) and let users choose!
Day 7: Quiz Game Builder
Final Project
Combine everything you've learned to build a complete quiz game with questions, scoring, and feedback. This is your masterpiece!
Your Mission:
Create a quiz game with at least 5 questions. Store questions and answers, check user responses, keep score, and give a final grade with encouraging feedback.
💡 New Concepts:
  • Dictionaries: {"question": "answer"}
  • Or use lists of lists to store questions
  • Percentage calculations
  • Conditional feedback based on score
🌟 Bonus Challenge:
Add multiple choice questions, a timer, or let users choose quiz topics!
